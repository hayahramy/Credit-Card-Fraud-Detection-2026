# Credit Card Fraud Detection & Risk Analytics

## 1. Project Name

**Credit Card Fraud Detection & Risk Analytics**

---

## 2. Project Idea

This project aims to analyze credit card transactions to identify fraud patterns, understand suspicious transaction behavior, and generate data-driven insights that support fraud monitoring and risk analysis.

The project focuses on exploring transaction data, analyzing fraud-related indicators, evaluating key performance metrics, and presenting meaningful findings through data visualization and reporting.

## 6. Key Performance Indicators (KPIs)

The project will focus on relevant indicators, depending on the available dataset fields, including:

- Total Number of Transactions
- Number of Fraudulent Transactions
- Fraud Rate (%)
- Total Transaction Amount
- Fraudulent Transaction Amount, where applicable
- Fraudulent vs. Legitimate Transaction Distribution
- Fraud Patterns Across Available Transaction Attributes
